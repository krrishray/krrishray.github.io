# krrishray.me

Personal portfolio for [Krrish Ray](https://krrishray.me) — React + Vite + Tailwind.

## Local development

```bash
pnpm install
pnpm dev
```

## Production build

```bash
pnpm build
pnpm preview
```

Pushes to `main` build and deploy to GitHub Pages (custom domain `krrishray.me`).

In the GitHub repo: **Settings → Pages → Source → GitHub Actions**.
